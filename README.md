# Laboratorio de Debian 12

Este repositorio lo utilizaré para documentar las prácticas que realice con Debian 12 en una máquina virtual utilizando VirtualBox.

El objetivo es familiarizarme con Linux y aprender sobre la administración del sistema, el uso de la terminal, la configuración de redes y la solución de problemas comunes.

## Temas que trabajaré

- Comandos básicos de Linux.
- Manejo de archivos y directorios.
- Administración de usuarios y permisos.
- Procesos y servicios del sistema.
- Configuración y diagnóstico de redes.
- Seguridad básica en Linux.
- Resolución de problemas.

## Entorno de trabajo

- **Sistema operativo:** Debian 12
- **Máquina virtual:** VirtualBox
- **Herramientas:** Terminal de Linux

## Prácticas

Iré agregando las prácticas conforme las realice, incluyendo los comandos utilizados, una explicación de los resultados y capturas de pantalla cuando sea necesario.
